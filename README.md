# Daniel Joseph — Portfolio

Portfolio personnel de Daniel Joseph, développeur web junior et designer UX/UI junior.

🌐 **Site en ligne :** https://dj3363015-tech.github.io/portfolio/  
💻 **Code source :** https://github.com/dj3363015-tech/portfolio  
👤 **Profil GitHub :** https://github.com/dj3363015-tech

## Présentation du projet

Ce site personnel sert à présenter mon profil, mes compétences en développement web et en design d’interface, ainsi que mon objectif de trouver une première opportunité professionnelle. Je suis basé en Martinique et mobile vers Lyon et sa région.

## Fonctionnalités visibles dans le code

- Page d’accueil avec présentation du profil et liens d’action.
- Navigation par ancres vers le portfolio, les compétences, la section « À propos » et le contact.
- Menu mobile interactif piloté par JavaScript.
- Présentation des compétences en HTML, CSS, Figma, Git et GitHub.
- Mise en page de cartes de projets et d’illustrations d’interface.
- Apparition progressive de certains éléments lorsque l’utilisateur fait défiler la page, via `IntersectionObserver` lorsque cette API est disponible.
- Année du pied de page actualisée automatiquement en JavaScript.
- Structure HTML en français avec balises sémantiques, attributs d’accessibilité et prise en charge de la mise en page mobile via la feuille de styles.

## Technologies

- **HTML** — structure et contenu.
- **CSS** — mise en page, styles et adaptation aux écrans.
- **JavaScript** — menu mobile, année dynamique et animations d’apparition.
- **Git et GitHub** — gestion du code source et hébergement du projet.

## Étude de cas

### Objectif
Créer un espace professionnel simple où un recruteur peut découvrir mon profil, mes compétences et mes liens de contact.

### Démarche
1. Organiser le contenu en sections faciles à parcourir.
2. Mettre en avant le profil et l’objectif professionnel dès la page d’accueil.
3. Ajouter une navigation mobile et des liens directs vers les ressources pertinentes.
4. Présenter les compétences et le projet sans prétendre à une expérience professionnelle qui n’a pas été déclarée.

### Ce que j’apprends
Ce projet me permet de pratiquer la structuration HTML, le style CSS, l’interactivité JavaScript et la publication d’un site avec GitHub.
